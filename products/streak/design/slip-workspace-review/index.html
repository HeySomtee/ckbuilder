    PERFORMANCE PROPOSAL

    An open pool still takes
    the long route.

    Even a repeat bet currently needs the sponsor to co-sign. Review also repeats live wallet, market, fixture and funding-history checks. Some reads run sequentially.

    1. Measure each stage first.Record review, sponsor queue, wallet request, broadcast and confirmation separately, without logging signatures.
    2. Shorten the review path.Share duplicate reads within one request, run independent checks with bounded concurrency and avoid fetching the entire fixture catalogue for every pick.
    3. Keep freshness where it matters.Cache stable metadata, but recheck spendable inputs, market deadlines, exact totals and wallet identity before signing.
    4. Make waiting legible.Show the actual stage, preserve the signed transaction and let you keep browsing. Already-open markets never show a setup step.

    These are proposed changes, not measured speed gains. Confirmation still depends on the network. The demo's short delays are not a promise.
